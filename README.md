# 💰 XpenseSplitter

XpenseSplitter is an Android application that makes managing shared expenses simple and hassle-free. Whether you're traveling with friends, sharing an apartment, or splitting restaurant bills, the app automatically keeps track of who paid, who owes, and each member's balance.

Built using **Java** and **Firebase**, the application provides secure authentication, real-time data synchronization, and an intuitive interface for managing group expenses.

---

## ✨ Features

- 🔐 User Authentication using Firebase
- 👥 Create and manage expense groups
- 💸 Add shared expenses
- 🧮 Automatic expense splitting
- 📊 View individual balances
- 🔄 Real-time synchronization with Cloud Firestore
- 📱 Clean and user-friendly Android interface

---

## 🛠 Tech Stack

- **Language:** Java

## 🚀 Getting Started

### Prerequisites

- Android Studio
- Java JDK 11 or later
- Firebase Project

### Installation

1. Clone the repository

```bash
git clone https://github.com/Jeyxnth/XpenseSplitter.git
```

2. Open the project in Android Studio.

3. Connect the project to your Firebase account.

4. Add the `google-services.json` file inside the `app` folder.

5. Sync Gradle and run the application.

---

## 📱 How It Works

1. Create an account or log in.
2. Create a new expense group.
3. Add members to the group.
4. Record expenses by selecting who paid.
5. The app automatically calculates each member's share.
6. View balances to know who owes whom.
